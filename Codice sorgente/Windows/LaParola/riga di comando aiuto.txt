This is a list of the possible commands for the command line, with the necessary syntax.\par
The words in {\i italics} have to be substituted with whatever you want to use.\par
The parts in [square brackets] are optional.\par
For {\i text}, you can use the name of a translation of the Bible or collection of notes (and only in that case you have to correctly type the upper and lower case letters) or the abbreviation of a translation or collection. If one is not given, the last translation is used (the one at the bottom right of the main window of the program).\par
If there is a space in the phrase, passage or text, you need to put it between "inverted commas".\par
You can put several commands in one line, separating them with a semi-colon.\par
