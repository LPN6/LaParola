Questa sezione contiene il codice sorgente delle app di LaParola.



1. Windows. Puoi usare Visual Studio di Microsoft per aprire il progetto e creare il programma. Se chiede una password, usa bibbia. Questa app funziona anche su Linux, se Mono 2.0 è installato.
2. Apple. Puoi usare XCode di Apple per aprire il progetto. Contiene il codice sia per l'app per iOS sia per macOS.
3. Android. Puoi usare Android Studio per aprire il progetto.
