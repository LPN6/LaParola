Ci sono due tipi di file:



Quelli con del tipo import....txt contengono la struttura del database, e i comandi per importare i dati. Di solito i comandi vengono eseguiti in un programma per gestire un database MySQL.

Tutti gli altri file contengono i dati che vengono importati nel database. In alcuni casi, un file è stato diviso in due file A e B, mentre GitHub ha un limiti di 100Mb per file. Bisognerebbe unire i due file in uno prima di importare.
