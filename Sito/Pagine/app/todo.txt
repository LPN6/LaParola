Per aggiungere un nuovo testo:
  Per Bible OSIS, usa ConvertiPerWebApp in VS2019>Projects
Controlla nomi dei libri and 'chapters' type in info.json
In CommandLine, npm run build:content
Copiare app/content/texts/ a siti>LaParola>app

To create a "build" version, you'll need uglify-js [best not to do this, as it doesn't include my personalising of index.html]
1. Install dependencies (if you haven't already): `npm install`
2. Rename `app/js/core/config-custom-example.js` to `app/js/core/config-custom.js` and update configs to your needs
3. Run `npm run build` (creates build files to use with index-build.html)
